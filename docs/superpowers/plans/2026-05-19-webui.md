# WebUI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an embedded browser-based kanban board interface accessible via `kanban webui`, with full TUI parity including drag-and-drop, live updates via SSE, and vanilla HTML/CSS/JS frontend.

**Architecture:** Axum HTTP server serves static files from `webui/static/` and exposes REST API + SSE. Each REST handler calls existing `Store` methods and broadcasts SSE events after mutations. Frontend is vanilla JS mirroring the TUI's 3-panel layout.

**Tech Stack:** Rust, axum 0.8, tower-http (fs), mime_guess, tokio sync, async-stream, vanilla HTML5/CSS3/ES6.

**Type definitions:**
```rust
use serde::Serialize;

#[derive(Debug, Clone, Serialize)]
pub struct ServerSentEvent {
    pub event: String,   // "card_created", "card_moved", etc.
    pub data: serde_json::Value,
}

impl ServerSentEvent {
    pub fn card_created(card: &crate::board::card::Card) -> Self {
        Self {
            event: "card_created".to_string(),
            data: serde_json::to_value(card).unwrap_or_default(),
        }
    }

    pub fn card_moved(card_id: &str, new_column: &str, new_column_name: &str) -> Self {
        Self {
            event: "card_moved".to_string(),
            data: serde_json::json!({
                "card_id": card_id,
                "new_column": new_column,
                "new_column_name": new_column_name
            }),
        }
    }

    pub fn card_updated(card_id: &str) -> Self {
        Self {
            event: "card_updated".to_string(),
            data: serde_json::json!({ "card_id": card_id }),
        }
    }

    pub fn card_deleted(card_id: &str) -> Self {
        Self {
            event: "card_deleted".to_string(),
            data: serde_json::json!({ "card_id": card_id }),
        }
    }
}
```

**Handler — SSE endpoint:**
```rust
use axum::{
    http::StatusCode,
    response::{IntoResponse, Response, Sse},
    Extension,
};
use axum::response::StreamBody;
use futures::Stream;
use std::pin::Pin;
use tokio::sync::broadcast;
use tokio_stream::StreamExt;

pub struct AppState {
    pub broadcaster: broadcast::Sender<ServerSentEvent>,
}

pub async fn sse_handler(
    Extension(app): Extension<AppState>,
) -> Response {
    let rx = app.broadcaster.subscribe();
    
    let stream = async_stream::stream! {
        let mut rx = rx;
        loop {
            match rx.recv().await {
                Ok(event) => {
                    let data = match serde_json::to_string(&event.data) {
                        Ok(s) => s,
                        Err(_) => continue,
                    };
                    yield Ok::<_, axum::BoxError>(
                        format!("event: {}\ndata: {}\n\n", event.event, data)
                    );
                }
                Err(broadcast::error::RecvError::Lagged(n)) => {
                    // Client is too slow, skip lagged events
                    tracing::debug!("SSE client lagged by {} events", n);
                }
                Err(broadcast::error::RecvError::Closed) => break,
            }
        }
    };
    
    Sse::new(stream)
        .with_keep_alive(axum::response::sse::KeepAlive::new().interval(std::time::Duration::from_secs(15)))
        .into_response()
}
```

**Dependencies needed:** `futures`, `async-stream`, `tokio-stream` (all common in the axum ecosystem).

**Key behaviors to test:**
1. SSE handler returns `text/event-stream` content type
2. Broadcasted events arrive at subscribed clients
3. Lagged clients get skipped (RecvError::Lagged is handled)
4. Connection stays alive (KeepAlive sends periodic keepalives)

**Implementation notes:**
- Use `async-stream` crate for the `stream!` macro (lightweight, no extra runtime)
- KeepAlive at 15s prevents proxy timeout issues
- `tracing` crate already available through axum's transitive deps, or use `eprintln!` for simplicity
- The `broadcaster` is cloned and shared as `AppState::broadcaster` across all handlers

```rust
pub async fn move_card(
    Path(card_id): Path<String>,
    State(app): State<AppState>,
    Json(body): Json<MoveRequest>,
) -> Result<Json<Card>, AppError> {
    let mut store = open_store(&app)?;
    let board = store.get_board(&app.project_path.to_string_lossy())?;
    
    let target_col = board.columns.iter()
        .find(|c| c.name == body.column)
        .ok_or_else(|| AppError::Bad(format!("Column '{}' not found", body.column)))?;
    
    // Update DB
    store.transition_card(&card_id, &target_col.id)?;
    
    // Update markdown file
    let card = store.get_card(&card_id)?;
    let mut updated = card.clone();
    updated.column_id = target_col.id.clone();
    markdown::writer::sync_card(&updated, &config::cards_dir(&app.project_path)).ok();
    
    // Broadcast SSE
    app.broadcaster.send(ServerSentEvent::card_moved(
        &card_id, &body.column, &target_col.name,
    )).ok();
    
    Ok(Json(updated))
}
```

**Server setup (`src/webui/server.rs`):**
```rust
#[cfg(feature = "webui")]
pub fn run(project_path: PathBuf) -> Result<()> {
    let (broadcaster, _) = broadcast::channel(100);
    
    let state = AppState {
        project_path,
        broadcaster: broadcaster.clone(),
    };
    
    let app = Router::new()
        .route("/api/boards", get(list_boards))
        .route("/api/cards", get(list_cards).post(create_card))
        .route("/api/cards/search", get(search_cards))
        .route("/api/cards/:id", get(get_card).patch(update_card).delete(delete_card))
        .route("/api/cards/:id/move", post(move_card))
        .route("/api/events", get(sse::sse_handler))
        .nest("/static", get_static_files())
        .with_state(state)
        .layer(Extension(state));  // For SSE handler
    
    // Serve on 127.0.0.1:9876
    let listener = tokio::net::TcpListener::bind("127.0.0.1:9876")?;
    println!("WebUI running at http://localhost:9876");
    tokio::runtime::Runtime::new()?.block_on(axum::serve(listener, app))?;
    
    Ok(())
}
```

**Static file serving:**
```rust
async fn static_files(Path(mut file): Path<String>) -> impl IntoResponse {
    let path = PathBuf::from("webui/static").join(&file);
    let content_type = mime_guess::from_path(&path).first_or_text/plain);
    
    match tokio::fs::read(&path).await {
        Ok(contents) => Response::builder()
            .header(header::CONTENT_TYPE, content_type.as_ref())
            .body(contents.into()),
        Err(_) => (StatusCode::NOT_FOUND, "Not found").into_response(),
    }
}
```

4. `POST /api/cards/:id/move` moves a card, updates markdown, broadcasts SSE

**Implementation notes:**
- All handlers follow the pattern: open store → call store method → broadcast SSE → return JSON
- The `update_card` handler uses the existing `store.update_card()` which takes optional fields — parse the JSON body into an `UpdateRequest` and extract `Some()` for present fields
- `create_card` needs to also call `markdown::writer::sync_card()` after DB insert (same pattern as CLI `create`)
- For `list_cards`, group cards by column: fetch all columns, then for each column fetch its cards, building `ColumnView` structs matching the TUI format
- Use `serde_json::Value` for request bodies and extract fields with `body.get("title").and_then(|v| v.as_str())` pattern — avoids defining separate serde structs for every endpoint

const API = {

    const res = await fetch(`/api${path}`);

function renderCardsPanel() {
  const cards = getCurrentCards();
  const container = document.getElementById('cards-list');
  container.innerHTML = '';
  
  if (cards.length === 0) {
    container.innerHTML = '<div class="card-item" style="color:var(--text-dim)"> (empty) </div>';
    return;
  }
  
  cards.forEach((card, i) => {
    const div = document.createElement('div');
    div.className = `card-item${i === state.cardSelection ? ' selected' : ''}`;
    div.draggable = true;
    div.dataset.idx = i;
    div.dataset.id = card.id;
    
    const priorityCh = priorityChar(card.priority);
    const title = card.title.length > 30 ? card.title.slice(0, 27) + '…' : card.title;
    div.textContent = `${priorityCh} ${card.id.slice(0, 8)} ${title}`;
    
    // Drag events
    div.addEventListener('dragstart', (e) => {
      e.dataTransfer.setData('text/plain', card.id);
      e.dataTransfer.effectAllowed = 'move';
    });
    
    container.appendChild(div);
  });
  
  // Make column area a drop target
  const cardsPanel = document.getElementById('cards-panel');
  const currentCol = state.columns[state.currentColumnIdx];
  cardsPanel.addEventListener('dragover', (e) => {
    e.preventDefault();
    e.dataTransfer.dropEffect = 'move';
    cardsPanel.style.outline = '2px solid var(--border-active)';
  });
  cardsPanel.addEventListener('dragleave', () => {
    cardsPanel.style.outline = '';
  });
  cardsPanel.addEventListener('drop', (e) => {
    e.preventDefault();
    cardsPanel.style.outline = '';
    const cardId = e.dataTransfer.getData('text/plain');
    const targetColName = currentCol ? currentCol.name : '';
    if (cardId && targetColName) {
      moveCard(cardId, targetColName);
    }
  });
}

**Implementation notes:**
- No build step — plain `<script src="...">` in HTML
- Use `fetch` API for HTTP calls (no axios/fetch polyfill needed for modern browsers)
- Use `EventSource` API for SSE (native browser support)
- HTML5 drag-and-drop API for card movement (native, no library)
- `escapeHtml()` utility to prevent XSS in rendered card content
- All DOM manipulation is direct — no virtual DOM, no framework
- `render()` is called after every state change — fine for a single-user kanban board with < 1000 cards
