> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an embedded browser-based kanban board interface accessible via `kanban webui`, with full TUI parity including drag-and-drop, live updates via SSE, and vanilla HTML/CSS/JS frontend.

**Architecture:** Axum HTTP server serves static files from `webui/static/` and exposes REST API + SSE. Each REST handler calls existing `Store` methods and broadcasts SSE events after mutations. Frontend is vanilla JS mirroring the TUI's 3-panel layout.

**Tech Stack:** Rust, axum 0.8, tower-http (fs, trace), mime_guess, async-stream, tokio-stream, vanilla HTML5/CSS3/ES6.

```rust
use serde::Serialize;

#[derive(Debug, Clone, Serialize)]
pub struct ServerSentEvent {
    pub event: String,   // "card_created", "card_moved", etc.
    pub data: serde_json::Value,
}

impl ServerSentEvent {
    pub fn card_created(card: &crate::board::card::Card) -> Self {
        Self {
            event: "card_created".to_string(),
            data: serde_json::to_value(card).unwrap_or_default(),
        }
    }

    pub fn card_moved(card_id: &str, new_column: &str, new_column_name: &str) -> Self {
        Self {
            event: "card_moved".to_string(),
            data: serde_json::json!({
                "card_id": card_id,
                "new_column": new_column,
                "new_column_name": new_column_name
            }),
        }
    }

    pub fn card_updated(card_id: &str) -> Self {
        Self { event: "card_updated".to_string(), data: serde_json::json!({ "card_id": card_id }) }
    }

    pub fn card_deleted(card_id: &str) -> Self {
        Self { event: "card_deleted".to_string(), data: serde_json::json!({ "card_id": card_id }) }
    }
}
```

**Handler — SSE endpoint (axum 0.8):**
```rust
use axum::{Extension, response::{Sse, Response, IntoResponse}};
use axum::response::sse::Event;
use tokio::sync::broadcast;

pub async fn sse_handler(
    Extension(state): Extension<AppState>,
) -> Response {
    let stream = async_stream::stream! {
        let mut rx = state.broadcaster.subscribe();
        loop {
            match rx.recv().await {
                Ok(sse_event) => {
                    let json_data = serde_json::to_string(&sse_event.data).unwrap_or_default();
                    yield Ok::<_, axum::BoxError>(Event::default()
                        .event(sse_event.event)
                        .data(json_data));
                }
                Err(broadcast::error::RecvError::Lagged(_n)) => {
                    eprintln!("SSE client lagged, skipping");
                }
                Err(broadcast::error::RecvError::Closed) => break,
            }
        }
    };
    Sse::new(stream).into_response()
}
```

**Key behaviors to test:**
1. SSE handler returns `text/event-stream` content type
2. Broadcasted events arrive at subscribed clients
3. Lagged clients get skipped (RecvError::Lagged is handled)
4. Connection stays alive (loop runs until client disconnects)

**Move handler pattern (applies to all mutation handlers):**
```rust
pub async fn move_card(
    Path(card_id): Path<String>,
    State(app): State<AppState>,
    Json(body): Json<MoveRequest>,
) -> Result<Json<Card>, ApiError> {
    let mut store = open_store(&app)?;
    let board = get_board(&app)?;
    
    let target_col = board.columns.iter()
        .find(|c| c.name == body.column)
        .ok_or_else(|| ApiError::bad_request(format!("Column '{}' not found", body.column)))?;
    
    // 1. Update DB
    store.transition_card(&card_id, &target_col.id)?;
    
    // 2. Update markdown file
    let updated = store.get_card(&card_id)?;
    let mut updated_card = updated.clone();
    updated_card.column_id = target_col.id.clone();
    crate::markdown::writer::sync_card(&updated_card, &config::cards_dir(&app.project_path))?;
    
    // 3. Broadcast SSE
    app.broadcaster.send(ServerSentEvent::card_moved(&card_id, &body.column, &target_col.name)).ok();
    
    Ok(Json(updated))
}
```

**Server setup:**
```rust
pub fn run(project_path: PathBuf) -> Result<()> {
    let rt = tokio::runtime::Builder::new_current_thread()
        .enable_all().build().context("Failed to create tokio runtime")?;

    rt.block_on(async {
        let (broadcaster, _) = tokio::sync::broadcast::channel(100);
        
        let app_state = AppState { project_path, broadcaster };
        let app = build_app(app_state.clone()).await;
        
        let listener = tokio::net::TcpListener::bind("127.0.0.1:9876")
            .await.context("Failed to bind to 127.0.0.1:9876")?;
        
        println!("WebUI running at http://localhost:9876");
        axum::serve(listener, app).await.context("WebUI server failed")?;
        
        Ok::<_, anyhow::Error>(())
    })
}

async fn build_app(app_state: AppState) -> Router {
    Router::new()
        .route("/api/boards", get(super::api::list_boards))
        .route("/api/cards", get(super::api::list_cards).post(super::api::create_card))
        .route("/api/cards/search", get(super::api::search_cards))
        .route("/api/cards/:id", get(super::api::get_card)
            .patch(super::api::update_card)
            .delete(super::api::delete_card))
        .route("/api/cards/:id/move", post(super::api::move_card))
        .route("/api/events", get(sse::sse_handler))
        .route("/static/*file", get(static_file))
        .route("/", get(root_handler))
        .with_state(app_state.clone())
        .layer(Extension(app_state))
        .layer(TraceLayer::new_for_http())
}
```

```rust
    let path = static_dir().join(&file);
```

**SSE + Polling Strategy:**
```javascript
function connectSSE() {
  const evtSource = new EventSource('/api/events');
  
  evtSource.addEventListener('card_created', () => refreshCurrentColumn());
  evtSource.addEventListener('card_moved', () => refreshAll());
  evtSource.addEventListener('card_updated', () => refreshCurrentColumn());
  evtSource.addEventListener('card_deleted', () => refreshCurrentColumn());
  
  evtSource.onerror = () => { console.log('SSE connection lost, reconnecting...'); };
  evtSource.close(); // Reconnect in polling interval below
  
  // Polling fallback every 3 seconds
  setInterval(async () => {
    try {
      const data = await API.get('/api/cards');
      const currentStr = JSON.stringify(state.columns.map(c => ({name: c.name, ids: c.cards.map(c2 => c2.id)})));
      const newStr = JSON.stringify(data.columns.map(c => ({name: c.name, ids: c.cards.map(c2 => c2.id)})));
      if (currentStr !== newStr) await loadBoard();
    } catch {}
  }, 3000);
}
```

## Execution Order

Tasks should be implemented in order: 1 → 2 → 3 → 4 → 5. Each task builds on the previous ones:

1. **Dependencies + skeleton** — `cargo check --features webui` passes, binary has `webui` subcommand
2. **SSE broadcaster** — standalone testable module (can mock a sender)
3. **REST API + server** — can test endpoints with `curl` or a browser
4. **Frontend HTML/CSS** — static files serve correctly, layout renders
5. **Frontend JS** — full interactive UI with REST + SSE

After all tasks, `kanban webui` running from an initialized project should show a fully functional kanban board in the browser with live updates.
